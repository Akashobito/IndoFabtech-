# Indofab Tech Landing Page

A modern and responsive landing page created for **Indofab Tech** using **React.js** and **Tailwind CSS**.  
The project focuses on a clean corporate design, smooth layout structure, and responsive user experience across mobile, tablet, and desktop devices.

## Features
- Responsive design for all screen sizes
- Clean and modern industrial landing page UI
- Built with React component structure
- Styled using Tailwind CSS utility classes
- Optimized layout for corporate branding

## Tech Stack
- React.js
- Tailwind CSS
- Vite

## Getting Started
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
npm install
npm run dev
```
